# Landing Scientific Methods Box

## Scope

The public Weight Test landing page now includes a dedicated section titled `Ашигласан шинжлэх ухааны аргачлалууд` immediately before the FAQ section.

## Included frameworks

- Биопсихосоциал загвар
- Dutch Eating Behavior Questionnaire — DEBQ
- Three-Factor Eating Questionnaire — TFEQ
- Binge Eating Scale — BES
- Night Eating Questionnaire — NEQ
- Когнитив-зан үйлийн функциональ шинжилгээ

## Claims boundary

The section states that Weight Test considered concepts studied within these frameworks. It does not claim that Weight Test is a direct translation, licensed implementation, clinical diagnostic tool, or psychometrically validated replacement for the named instruments.

## Implementation

- Public asset: `assets/landing-scientific-methods.js`
- Loaded from: `index.html`
- Placement: before `.faq-section`
- Layout: existing three-column methodology cards, responsive to one column on mobile
- Detail link: `/methodology`

## Package verification

Production and staging package manifests include the new public asset and its SHA-256 hash.
